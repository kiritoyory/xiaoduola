# 小哆啦 · 学习小助手

基于 Electron 的 Windows 桌面学习助手。默认是屏幕右下角的小型置顶桌宠；使用用户提供并授权的二维角色图片，待机时显示休息姿势，点击铃铛会短暂切换到挥手姿势；按住角色身体拖动即可移动，点击独立的「功能」按钮打开快捷菜单。进入功能后打开无角色的简洁面板；收起返回桌宠，隐藏后可从系统托盘唤起。

## 安装与启动

### 系统要求

- 当前桌面应用面向 **Windows 10/11**。
- 安装 **Node.js 22.12 或更高版本**（Electron 45 要求）。npm 会随 Node.js 一起安装。
- 获取本项目源码并解压。安装和启动命令必须在包含 `package.json` 的项目文件夹中运行，不要在 `C:\Users\你的用户名` 等其他目录直接执行。

### 首次安装和启动

打开 PowerShell，将下面的路径替换为你电脑上实际的项目文件夹路径：

```powershell
cd "C:\path\to\桌宠小哆啦"
Test-Path .\package.json
```

如果 `Test-Path` 显示 `True`，说明目录正确。再运行：

```powershell
npm install
npm start
```

`npm install` 只需在首次运行或依赖更新后执行；`npm start` 会启动桌宠。

后续可以在 PowerShell 进入同一项目文件夹，再运行：

```powershell
cd "C:\path\to\桌宠小哆啦"
npm start
```

桌宠会以置顶小窗口出现。点击角色可以互动，点击「功能」打开工具面板；在桌宠或应用窗口中右键并选择「隐藏桌宠」可将其隐藏，之后可从系统托盘重新显示。

也可以双击项目内的 `启动桌宠.vbs` 启动，启动后无需保持 PowerShell 窗口打开。推荐创建**桌面快捷方式**（右键 `启动桌宠.vbs` →「发送到 → 桌面快捷方式」）。如果只把 `.vbs` 文件复制到桌面，脚本会尝试通过桌面快捷方式找到项目目录；若找不到，请使用快捷方式或从项目文件夹重新创建。

如果把整个项目文件夹复制或移动到新的位置，先在新位置的项目文件夹运行 `npm install`，再双击里面的 `启动桌宠.vbs`。旧位置创建的桌面快捷方式仍指向旧路径，需要从新位置重新创建快捷方式。

### 可选：Agent Reach 联网搜索

联网搜索需要另行安装 Agent Reach，并完成它的初始化。请遵循 [Agent Reach 官方安装指南](https://raw.githubusercontent.com/Panniantong/Agent-Reach/main/docs/install.md)。该功能仅在 Agent Reach 已安装且命令行可用时生效；其他桌宠功能不依赖它。

### 常见问题

- **提示找不到 `npm`**：请安装 Node.js 22.12 或更高版本，然后关闭并重新打开终端。
- **桌宠没有出现**：检查系统托盘中是否有「学习小助手」图标，或在项目文件夹重新运行 `npm start`。
- **安装依赖时报错**：确认网络可用、Node.js/npm 已安装，并且终端当前位于包含 `package.json` 的项目文件夹；再运行 `npm install`。

开发时可运行 `npm run check` 检查 JavaScript 语法。

## 功能

- 按文件扩展名预览并整理选定目录中的文件；仅扫描当前目录，操作前需再次确认，同名文件不会覆盖。
- 本地保存待办提醒、每周课表和备忘；桌面通知在应用运行期间生效，课表在开课前 10 分钟提醒。
- 从 CSV 或 JSON 导入课表。CSV 表头示例：`课程名,星期,时间,地点`；星期为 1-7（周一到周日），时间为 `HH:mm`。JSON 接受对象数组，字段可使用 `title/day/time/location`，也可使用 `name/weekday/time/place`。
- AI 和新闻走中央服务。「设置」使用邮箱/密码登录；普通账号需使用管理员生成的一次性邀请码。中央管理员统一设置共享模型和新闻源，模型密钥仅放在中央服务器环境变量中，不下发到桌宠客户端。
- 新闻播报会朗读来源中的重点标题，并列出可打开的官方新闻/视频/音频来源链接；应用不提取或复制第三方视频音轨。
- 在「设置」可导入本机 WAV/MP3 互动语音及自定义铃铛互动台词。录音保存在本机用户数据目录，不上传中央服务器；触发铃铛时优先播放导入录音。
- Agent Reach 已作为本机只读联网能力接入「联网」页和聊天指令；支持按已安装渠道搜索，也可粘贴 HTTP(S) 链接读取。Windows CLI 安装后需确保 `%USERPROFILE%\.local\bin` 在 PATH 中。
- 日常语音和新闻朗读依赖 Windows 已安装的语音合成；在「玩耍」页可选择中文语音并试听。默认优先选择 Yaoyao 中文语音，语速和音调略作调整，长内容会分段播报。声音使用系统语音，不包含哆啦A梦原声；可在 Windows 语音设置中安装其他中文语音。
- 系统托盘可显示/隐藏桌宠；页面内含点击互动和泡泡小游戏。

### 中央服务部署（管理员）

中央服务尚未托管；需要管理员先部署服务，所有人的账号和共享 AI/新闻功能才可使用。智谱的 `https://open.bigmodel.cn/apikey/platform` 是 API 密钥管理页面，不是桌宠中央服务地址。

1. 在服务器上安装 Node.js 22.12 或更高版本，将项目的 `server` 文件夹复制到服务器。
2. 在该文件夹运行 `npm install`。
3. 首次启动前配置环境变量 `ADMIN_EMAIL`、至少 12 位的 `ADMIN_PASSWORD` 和智谱 `BIGMODEL_API_KEY`；可选设置 `PORT`（默认 8787）和 `DATA_DIR`（默认 `server/data`）。
4. 运行 `npm start`。服务仅监听 `127.0.0.1`，需用支持 HTTPS 的反向代理发布；不要直接把未加 TLS 的端口暴露到公网。`GET /health` 可用于健康检查。
5. 在桌宠「设置」中填入反向代理的 HTTPS 根地址，以管理员邮箱登录；设置共享模型与新闻源，并生成一次性邀请码给普通用户注册。

模型密钥只读服务器环境变量。更换密钥需要在服务器更新 `BIGMODEL_API_KEY` 并重启服务；请勿把密钥放到客户端或提交到版本库。SQLite 用户/会话数据在 `server/data`，请设置服务器文件权限并定期备份。当前服务 scaffold 尚未自动配置域名、HTTPS 证书、邮件找回或托管；部署前应为管理员使用强密码并限制服务器访问。

AI 和新闻服务可能产生费用，并受服务商隐私条款约束。未连接中央服务时，文件整理、课表、提醒、备忘和小游戏仍可本地使用。
